03 / NOTES

观影手记

NOTE 01《七武士》在 207 分钟里没有一分钟是闲着的

雨戏占了结尾整整二十分钟，泥地里分不清人影，但每一次挥刀的方向都清楚。看大银幕版本时请务必选中间偏后的座位，前排会被溅起的泥点晃到视线。

by 老周 · 写于 C 厅散场后

NOTE 02《花样年华》适合在雨天下午两点看

98 分钟里大半是走廊、旗袍、错身而过。灯亮得太早会出戏，建议避开晚场，选人少的午后场，出来时天还没黑，情绪才收得住。

by 阿棠 · 二刷记录

NOTE 03《罗马》的黑与白并不是怀旧

长镜头横着推过院子、过道、产房，镜头不动，人在动。第一次看容易走神，第二次看才发现声音做得比画面满，海浪声一直压在底下。

by 小林 · 家庭厅观看

NOTE 04《闪灵》的恐怖来自空旷，不是血

走廊地毯的花纹、走廊尽头那一对双胞胎，看得越清楚越冷。散场后建议别立刻看解说，先把结尾那张老照片自己想一遍。

by 夜场常客 · 三刷

04 / CLUB

影迷聚点 · 常被问到的几句

问题来自站内留言，回答每月整理一次，删掉过期的那部分。

  • 排片多久更新一次？

    每日零点前换一次当日表，临时调换会在放映前一小时改标。遇上节假日加场，表格里会多出一行“加”。

  • 能不能按片长筛片？

    可以。每张卡片下边都标了分钟数，90 分钟以内适合通勤后看，150 分钟以上的建议排进周末。

  • 手机端看着排版乱怎么办？

    本站为窄屏重排过：放映单在手机上会折成两行，片库墙变两列。横屏、字体放大到 18px 以上都不影响阅读。

  • 片单的信息从哪来？

    取自公开的院线公告与影片资料整理，只做索引与短评，不提供任何下载、在线播放与资源链接。

  • 想推荐一部片子进来？

    记下年份、地区、片长三项就够，按这个格式留在本页留言区，我们核对后加进片库墙，下一轮更新时会出现在卡片里。

  • 站名和入口地址怎么写才不会找错？

    站名是“琪琪影视”，入口是 https://qiqiyingshi-app.github.io ，照抄这一串字母即可，前后都没有多余的后缀。

关于琪琪影视这一页

琪琪影视做的是一件小事：把当天放什么、片库里有什么、看完的人说了什么，收在一页里按顺序排好。不做推荐算法，不按热度排序，卡片的位置只和入库先后有关。

全站信息来自公开资料整理，仅提供索引与短评，不提供任何影视资源的下载、在线播放或跳转链接。
